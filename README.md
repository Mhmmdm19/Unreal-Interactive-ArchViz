# Interactive ArchViz Configurator (Unreal Engine)

An open-source, real-time interior design and architectural customization tool built using **Unreal Engine 5**. This project provides an interactive framework allowing users to explore and personalize various architectural spaces in a first-person perspective.

## 🚀 Key Features

- **Multi-Environment Hub:** A main menu system connecting 20 to 30 highly detailed, customizable interior spaces (bathrooms, kitchens, living areas, etc.).
- **FPS Interaction System:** Seamless camera movement with a central reticle (crosshair) serving as the user's selector guide.
- **Line Trace Detection:** Advanced raycasting mechanism to precisely identify and select different architectural elements like walls, floors, and fixtures.
- **Runtime Material Swapping:** A dynamic UMG user interface linked with Material Instances to swap textures (ceramics, tiles, stone, paint) in real-time without losing lighting quality.

## 🛠️ Tech Stack & Concepts
- **Engine:** Unreal Engine 5
- **Scripting:** Blueprints Visual Scripting
- **UI System:** Unreal Motion Graphics (UMG)
- **Materials:** Dynamic Material Instances & Data Tables

## 🎯 Project Goal & Open Source Vision
The main objective of this repository is to share the core blueprint logic, interaction templates, and UI frameworks with the ArchViz and indie game development community. Students, 3D artists, and developers can use this repository as a comprehensive template to kickstart their own interactive configurators.
